**Drag captions anywhere.** This update lets you place captions freely on your video, the most requested change from the first alpha. Thanks to everyone who tested v0.1.0-alpha!

> ⚠️ **Alpha.** Expect rough edges. Report problems at https://github.com/kreokit/captions/issues, or from the app: **⋯ → Report a problem**.

## What's new in 0.1.1

- **Drag captions anywhere on the video.** Hover the caption to see its outline and grip, then drag it. It snaps to the centre and to the old Top / Bottom spots, with thin guide lines; hold **⌥ Option / Alt** to place it freely. **Double-click** the caption to send it back to bottom centre.
- **Exact position:** X and Y fields (in % of the frame) in the Style tab, next to the Top / Middle / Bottom quick presets.
- **Place captions even when none is playing:** with the Style tab open (or the pointer over the video), the nearest caption shows dimmed so you can still drag it.
- **Social safe area:** a "Show social safe area" switch shades the parts of vertical videos that TikTok, Reels and Shorts cover with their buttons, so your captions stay readable there.
- **Captions always stay inside the frame.** They can't be dragged off-screen, and text too wide for the frame (for example big captions on vertical videos) is shrunk just enough to fit. The Style tab tells you when that happens.
- **What you see is what you export:** the burned-in MP4 and the `.ass` file put captions exactly where the preview shows them, on vertical and wide videos alike.
- **Report a problem** from the app's **⋯** menu.

Projects from 0.1.0 open as before; their captions stay where they were.

## Installing an unsigned app

The alpha isn't signed with paid developer certificates, so your system will warn you the first time.

**macOS**
1. Open the `.dmg` and drag **KreoKit Captions** to Applications.
2. Open it. If macOS says it "can't be opened" or "can't verify the developer", open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**, then confirm.
3. If macOS instead says the app "is damaged and can't be opened", that is the same missing signature, not real damage. Run this once in Terminal, then open the app again:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/KreoKit Captions.app"
   ```

**Windows**
1. Run the `…-setup.exe` installer.
2. If SmartScreen says "Windows protected your PC", click **More info → Run anyway**.

**Linux**
- AppImage: `chmod +x KreoKit.Captions_*.AppImage`, then run it.
- Debian / Ubuntu: `sudo apt install ./KreoKit.Captions_*_amd64.deb`.

## Known limitations

- Transcription runs on the CPU everywhere (no GPU acceleration yet), so long videos take a while on older machines.
- MKV and AVI files transcribe and export, but the editor can't preview them yet.
- No undo yet, and closing the window doesn't ask about unsaved changes (the Home button does).
- Exported `.ass` files name the caption font but don't include it; install the font where you play them.
- The Windows and Linux downloads are large because of the bundled FFmpeg.
