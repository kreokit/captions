## What's fixed in 0.1.2

- **No more crash when transcribing on macOS 12 and early macOS 13** (Intel and Apple Silicon). The macOS downloads used a speed-up from Apple's math library that only exists on macOS 13.3 and later. On older versions the app crashed as soon as transcription started. It now uses the version of that speed-up that every macOS has, so transcription runs at the same speed as before.
- New release checks: every download is now test-transcribed in the build, and the macOS apps are checked for anything that needs a newer macOS than 12.

Windows and Linux had no crash. They get 0.1.2 too, so every platform is on the same version. Nothing else changed since 0.1.1, and projects open as before.

## Installing an unsigned app

The alpha isn't signed with paid developer certificates, so your system will warn you the first time.

**macOS**
1. Open the `.dmg` and drag **KreoKit Captions** to Applications (replace the old version if asked).
2. Open it. If macOS says it "can't be opened" or "can't verify the developer", open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**, then confirm.
3. If macOS instead says the app "is damaged and can't be opened", that is the same missing signature, not real damage. Run this once in Terminal, then open the app again:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/KreoKit Captions.app"
   ```

**Windows**
1. Run the `…-setup.exe` installer.
2. If SmartScreen says "Windows protected your PC", click **More info → Run anyway**.

**Linux**
- AppImage: `chmod +x KreoKit.Captions_*.AppImage`, then run it.
- Debian / Ubuntu: `sudo apt install ./KreoKit.Captions_*_amd64.deb`.

## Known limitations

- Transcription runs on the CPU everywhere (no GPU acceleration yet), so long videos take a while on older machines.
- MKV and AVI files transcribe and export, but the editor can't preview them yet.
- No undo yet, and closing the window doesn't ask about unsaved changes (the Home button does).
- Exported `.ass` files name the caption font but don't include it; install the font where you play them.
- The Windows and Linux downloads are large because of the bundled FFmpeg.
